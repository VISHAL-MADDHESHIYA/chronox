# ⏱️ ChronoX — Advanced Countdown Timer

A modern, lightweight countdown timer built with **pure vanilla JavaScript** — zero dependencies.

## 🌐 Live Demo

👉 [View Live](https://vishal-maddheshiya.github.io/chronox/)
👉 [GitHub repo](https://github.com/VISHAL-MADDHESHIYA/chronox)



## ✨ Features

- ⏱️ Live countdowns updating every second
- ✦ Featured event card for your next milestone
- ⚡ Quick presets (1 hour, 24 hours, 7 days, 30 days)
- 🎨 Dark mode + 5 accent colors
- 💾 LocalStorage persistence
- 📤 Export/Import JSON backups
- 🔔 Browser notifications + completion sound
- 📱 Fully responsive design
- ♿ Accessibility (ARIA, keyboard shortcuts)

## 🛠️ Tech Stack

- **HTML5** — semantic markup, native `<dialog>`
- **CSS3** — custom properties, grid, responsive
- **Vanilla JavaScript** — ES6 modules, zero libraries
- **Web APIs** — Intl, AudioContext, Notification, localStorage
